# tvpipe

A small, cross-platform Rust command line tool for low-latency mirroring of
video and audio to **AirPlay** and **Google Cast** receivers.

Status: planning. See:

- [`PLAN.md`](PLAN.md): goals, architecture, protocols, milestones, risks
- [`MULTI_AGENT.md`](MULTI_AGENT.md): how to build it with several agents,
  including the FairPlay clean-room process
- [`AGENTS.md`](AGENTS.md): rules for agents working in this repository
