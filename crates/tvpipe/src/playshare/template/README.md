# {{title}}

A party game for tvpipe, made with `tvpipe game new`:
the host page (`host/`) keeps the rules, the TV page (`tv/`) is cast to
the TVs, phones open the phone page (`phone/`).

    tvpipe game play .                    # play it (edit, then reload the page)
    tvpipe game check .                   # check it
    tvpipe game pack . -o {{name}}.zip    # pack it for others: tvpipe game play {{name}}.zip

tvpipe's docs/games.md has the whole story.
